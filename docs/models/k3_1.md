# Kimi K3.1

按 [Kimi K3 指南](kimi_k3.md)准备环境，从 TorchTitan 根目录使用 8 张 NPU 启动。图文 debug 配方使用约 9.69B 的 17 层文本主干，含 12 层 KDA 和 5 层 DSA，注意力为 96 头，Indexer 为 32 头、128 维、Top-K 2048。

```bash
NGPU=8 ENTRYPOINT=torchtitan_ascend.train MODULE=torchtitan_ascend.recipes.kimi_k3_1 \
    CONFIG=kimi_k3_1_multimodal_debugmodel_npu ./run_train.sh
```

该配方使用 `cc12m-test`，默认上下文为 256 token，从随机权重开始，默认训练 10 步。

## Pro

`kimi_k3_1_pro_npu` 使用 [Moonshot 官方 K3.1 Pro 结构](https://huggingface.co/moonshotai/Kimi-K3.1-Pro/blob/main/config.json)，包含 93 层（69 层 KDA、24 层 DSA）、96 个注意力头、896 个路由专家（每 token 选 16 个）、163840 词表和 27 层视觉塔。

该配方使用 `cc12m` 流式数据，默认复用 TorchTitan 的 Kimi K3 多模态 tokenizer 和 `./tests/assets/tokenizer` 测试资产。若要使用其他兼容的 tokenizer 资产，在自定义 Python recipe 中通过 `hf_assets_path` 指定目录。

默认从随机权重开始，训练上下文为 2048 token，可在调用 recipe 时传入 `seq_len` 和 `parallelism`。

当前 DSA 参考实现要求 TP=CP=1。Pro 全量训练、长上下文和官方量化权重加载待验证。
